Real Squads

Import real (or better-than-generated) player names per nation. When a country's squad is generated for a match, an imported roster is used instead of the usual random names — everything else (ratings, positions, editing) works exactly the same.

Set this once and it re-loads automatically every time the page opens. Use a GitHub "Raw" link (not the regular github.com page link) or a jsDelivr link (cdn.jsdelivr.net/gh/USER/REPO@main/players.json) — both send the CORS headers a browser fetch needs.
Expects {"countries":[{"country":"Algeria","players":[{"name":"...","position":"RW"}, ...]}, ...]}. Positions can be detailed real-football shorthand (GK/RB/CB/LB/CDM/CM/RW/ST/LW, etc.) — they're mapped down to this game's GK/DF/MF/FW/ST automatically. Rosters with fewer than 11 players are padded out with generated names.
